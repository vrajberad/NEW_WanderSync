# WanderSync Backend Build Setup

## Required versions

- **Java:** JDK 21 (the supported build and runtime version).
- **Maven:** Maven 3.9 or later.
- **Spring Boot:** 3.3.5 (managed in `backend/pom.xml`; do not change for normal builds).

The Maven compiler is configured with `release=21`, so generated bytecode and Java APIs target Java 21. Maven should also be launched with a JDK 21 `JAVA_HOME`; compiling with a newer JDK is not the supported configuration.

## Lombok configuration

The project uses Lombok 1.18.38 for DTOs, models, builders, and logger fields. This explicit version is required because Spring Boot 3.3.5's managed Lombok 1.18.34 does not initialize on JDK 25, while the project must compile when a developer currently has a newer JDK installed. The Maven Compiler Plugin explicitly loads Lombok through `annotationProcessorPaths`. This avoids relying on implicit annotation-processor discovery, which newer JDKs disable or restrict.

If you use an IDE, also enable its Lombok annotation-processing support. IDE support does not replace the Maven configuration.

## Verify the active Java version

From `backend/`, run:

```bash
java -version
```

It must report Java 21. Then verify the JDK Maven actually uses:

```bash
mvn -version
```

The `Java version:` line must report 21.

## Build and test

Run these commands from the `backend/` directory:

```bash
mvn clean compile
mvn clean test
```

`mvn clean test` is the full verification command. The repository currently has no test sources, so a successful command validates compilation and reports zero tests rather than executing test cases.

## macOS setup

1. Install a JDK 21 distribution (for example, Temurin 21 or Oracle JDK 21).
2. In a terminal, select it for the current shell:

   ```bash
   export JAVA_HOME="$(/usr/libexec/java_home -v 21)"
   export PATH="$JAVA_HOME/bin:$PATH"
   ```

3. Confirm both `java -version` and `mvn -version` report Java 21.
4. Run `mvn clean test` inside `backend/`.

To persist this selection for zsh, place the two `export` lines in `~/.zshrc` after confirming the JDK path exists.

## Windows setup

1. Install JDK 21.
2. Set the `JAVA_HOME` system or user environment variable to the JDK 21 installation directory, for example `C:\Program Files\Java\jdk-21`.
3. Add `%JAVA_HOME%\bin` to `Path` before other Java installations.
4. Open a new Command Prompt or PowerShell window, then run:

   ```powershell
   java -version
   mvn -version
   cd backend
   mvn clean test
   ```

Both version commands must show Java 21.

## Common build problems

| Symptom | Cause and resolution |
|---|---|
| Missing Lombok getters, setters, builders, or `log` fields | Ensure the build uses this POM, run `mvn clean test`, and make sure the IDE has Lombok annotation processing enabled. |
| `mvn -version` shows Java 22+ or an older JDK | Correct `JAVA_HOME` and `Path`, open a new terminal, and verify again before building. |
| `release version 21 not supported` | Maven is running on a JDK older than 21. Install/select JDK 21. |
| Maven cannot resolve dependencies | Check network/proxy settings and retry; Spring AI requires the configured Spring Milestones repository. |
| Application starts but MongoDB is unavailable | This is not a compile error; start MongoDB or configure `MONGODB_URI`/the active Spring profile. |
